## 1. 项目概述

卡比大冒险是一款 2D 横版动作游戏，玩家通过键盘操控卡比在瓦片地图中移动、跳跃、漂浮，通过吸入敌人并吐出星星进行攻击，在生命值归零前达成通关条件（消灭全部敌人）。本说明书定义本期（8 天 Java 实训）开发范围内的功能与非功能需求。

**范围边界 / 明确不做**：变身能力（Copy Ability）、Boss 战、多关卡与关卡编辑、联网对战、存档系统、道具系统。（来源：客户材料 + Q3）

## 2. 术语表

- **卡比**：玩家操控的主角角色。
- **敌人**：由 AI 驱动的非玩家角色，可被吸入或消灭。
- **吸入**：卡比吸附前方一定范围内敌人的技能。
- **吐出星星**：卡比将吸入的敌人以星星弹丸吐出的攻击技能。
- **漂浮**：卡比充气后在空中向上移动/悬停的能力。
- **生命值**：卡比的存活点数，归零触发 Game Over。
- **瓦片地图**：基于 `.tmx` 文件的二维地图。
- **出生点**：卡比在一关开始时的初始位置。
- **通关**：达成胜利条件（消灭全部敌人）。

## 3. 用户与角色

- **玩家**：通过键盘操控卡比的最终用户。
- **重力/物理循环**（系统角色）：持续对卡比与敌人施加重力、推进碰撞检测，无人类交互。
- **敌人 AI**（系统角色）：驱动敌人自动巡逻，无人类交互。

> 参与者 ≥ 2 且含系统类参与者 ✓（共 3 名，其中 2 名系统角色）。

## 5. 用户故事

- **F01 开始游戏**：作为玩家，我希望从主菜单选择"开始游戏"，以便进入一局新游戏、从出生点开始挑战。
- **F02 左右移动**：作为玩家，我希望用左右方向键控制卡比移动，以便在关卡中穿行、躲避或接近敌人。
- **F03 跳跃与漂浮**：作为玩家，我希望按跳跃键起跳并长按漂浮，以便跨越沟壑、登上平台。
- **F04 地图加载与碰撞**：作为玩家，我希望游戏正确加载并渲染地图、提供地面与墙壁碰撞，以便在关卡中稳定行走、不穿墙、不掉出地图。
- **F05 敌人巡逻**：作为玩家，我希望敌人沿平台自动巡逻，以便关卡存在可预判的威胁。
- **F06 吸入与吐星**：作为玩家，我希望吸入敌人并吐出星星攻击，以便用招牌技能消灭敌人。
- **F07 踩怪消灭**：作为玩家，我希望从上方踩中敌人能将其消灭，以便在无法吸入时仍有保底消灭手段。
- **F08 受伤与生命值**：作为玩家，我希望被敌人触碰时损失生命值，以便游戏具有挑战性、促使我谨慎行动。
- **F09 结束判定**：作为玩家，我希望生命值归零时进入 Game Over 并能重新开始或返回菜单，以便结束一局并决定是否再来一局。

## 7. 活动图

### 7.1 敌人巡逻与转向（activity-enemy-patrol）

**PlantUML 源码**：

```
@startuml
start
:敌人出生;
repeat
  :朝当前方向移动;
repeat while (到达边缘或撞到障碍？) is (否)
->是;
:水平转向（移动方向取反）;
backward:回到移动;
stop
@enduml
```

**文字版（含判断框 + 回边）**：

```
● 开始（敌人出生）
│
[敌人朝当前方向移动]
│
◇ 到达平台边缘或撞到障碍？
│   否 ──回边──→ [敌人朝当前方向移动]   ← 回边：持续巡逻
│   是
[水平转向（方向取反）]
│
└──→ [敌人朝当前方向移动]
```

- 判断框 1 个 ✓，回边 1 条 ✓。

### 7.2 一局生命周期（activity-life-cycle）

**PlantUML 源码**：

```
@startuml
start
:开始一局（F01）;
repeat
  if (玩家按暂停？) then (是)
    :暂停（F10）;
    :等待玩家再次按暂停;
  else (否)
    :卡比移动/跳跃/漂浮（F02/F03）;
    :卡比与敌人交互（吸入吐星 F06 / 踩怪 F07）;
    if (卡比被敌人触碰（非踩怪/吸入中）？) then (是)
      :生命值 -1（F08）;
      if (生命值 = 0？) then (是)
        :Game Over（F09）;
        stop
      else (否)
      endif
    else (否)
      :敌人巡逻推进（F05）;
    endif
  endif
repeat while (生命值 > 0)
stop
@enduml
```

**文字版**：

```
● 开始一局
│
[开始游戏 F01]
│
◇ 玩家按暂停？
│   是 → [暂停 F10] → ◇ 玩家再按暂停 → 回到 ◇ 玩家按暂停   ← 回边 1：暂停循环
│   否
[卡比移动/跳跃/漂浮 F02/F03]
│
[卡比与敌人交互：吸入吐星 F06 / 踩怪 F07]
│
◇ 卡比被敌人触碰？（非踩怪、非吸入中）
│   是 → [生命值 -1 F08]
│         → ◇ 生命值 = 0？
│             是 → [Game Over F09] → ◉ 结束
│             否 ──回边──→ [卡比移动/跳跃/漂浮]   ← 回边 2：继续游戏
│   否 → [敌人巡逻推进 F05] → 回到 [卡比移动/跳跃/漂浮]
```

- 判断框 3 个 ✓，回边 2 条（暂停循环 + 继续游戏循环）✓。

## 8. 验收标准（Given-When-Then）

| # | 关联 | Given（前置） | When（操作） | Then（结果） |
| --- | --- | --- | --- | --- |
| 1 | F01 | 程序处于主菜单 | 玩家选择"开始游戏" | 进入游戏，卡比出现在出生点，生命值 = 3 |
| 2 | F02 | 卡比在地面，右侧无墙 | 玩家按住 → 键 | 卡比水平向右移动（水平速度 > 0） |
| 3 | F02 | 卡比紧贴右墙 | 玩家按住 → 键 | 卡比位置不变（不穿墙） |
| 4 | F03 | 卡比在地面 | 玩家按跳跃键 | 卡比获得向上的初速度并离地，随后受重力落回地面 |
| 5 | F03 | 卡比在空中 | 玩家长按跳跃键 | 卡比向上移动（垂直速度 > 0）；松开后受重力下落 |
| 6 | F04 | 关卡已加载，卡比前方是墙壁 | 卡比向墙移动 | 卡比被墙壁阻挡，位置不越过墙体 |
| 7 | F05 | 敌人位于平台，前方是平台边缘 | 敌人移动到边缘 | 敌人转向，朝相反方向移动 |
| 8 | F06 | 敌人位于卡比前方吸入范围内 | 玩家按吸入键后再按吐出键 | 敌人以星星弹丸射出；弹丸命中另一敌人则该敌人被消灭 |
| 9 | F07 | 卡比在空中且位于敌人正上方 | 卡比落下踩中敌人 | 该敌人被消灭 |
| 10 | F08 | 卡比生命值 = 3 | 卡比被敌人触碰 | 生命值减为 2 |
| 11 | F09 | 卡比生命值 = 1 | 卡比被敌人触碰 | 生命值 = 0，进入 Game Over 界面 |

> 每条 Then 均可转测试用例：Given 变前置数据、When 变被调方法、Then 变断言。无模糊词（全程未出现"流畅/合理/快速"等）。

## 9. 非功能需求
